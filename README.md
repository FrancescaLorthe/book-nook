# BookNook

BookNook is a simple web application for browsing and discovering books. It is designed like an independent bookstore website where users can explore different genres, view book details, and interact with basic shopping features.

---

## What This Project Does

BookNook allows users to:

- Browse a curated collection of books  
- View books organized by category (fiction, nonfiction, fantasy, etc.)  
- Add books to a shopping cart  
- Save or favorite books for later (stored in the browser)  
- Navigate through a clean, structured bookstore-style layout  

The goal of the project is to simulate a small online bookstore experience using only front-end technologies.

---

## Built With

- HTML  
- CSS  
- JavaScript  

---

## Features

### Book Browsing
Users can scroll through multiple categories of books with images, titles, authors, and prices.

### Shopping Cart
Books can be added to a cart using a simple JavaScript interaction system.

### Save / Favorite Books
Users can save books they like. Saved items are stored in the browser using localStorage so they remain after refresh.

### Responsive Layout
The layout adjusts for different screen sizes, making it usable on desktop and mobile devices.

---

## Purpose of the Project

This project was built to practice:

- Structuring multi-page websites  
- Working with JavaScript interactions  
- Managing browser storage (localStorage)  
- Creating a clean UI for content-heavy pages  

---

## Notes

This is a front-end only project.  
No backend or database is used — all saved data is stored locally in the browser.
